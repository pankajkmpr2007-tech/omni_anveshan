# Anveshan — Hackathon Website

Standalone static website for the Anveshan hidden-destination discovery prototype.

## Run locally
Open `index.html` in Chrome/Edge.

## Deploy
This folder is ready for GitHub Pages, Vercel, Netlify, or any static host.

### GitHub Pages
Push the folder to a repository, then enable Pages from the repository's Settings → Pages. Use the `main` branch and root folder as the publishing source.

### Vercel
Import the repository and deploy as a static site. No build command is required.
